# MiniMax H3 双卡扩散采样技能

给 Codex 的 Windows 本地推理技能。它将一条视频的每个扩散步拆给两张 NVIDIA 卡，提供经过验证的 ComfyUI API 工作流、独立环境搭建步骤、资源采样和成片验证方法。

在两张 RTX 4070 SUPER 12 GiB、96 GiB 系统内存上，720p / 5 秒 / 8 步单次对照中，采样从 8:48 缩短至 5:07，总耗时从 660.70 秒缩短至 391.22 秒；两版全部 120 帧解码像素一致。系统内存峰值从 68.77 增至 83.65 GiB。其他硬件需重新测量。
